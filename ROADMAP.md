# Productization roadmap

Working document — updated as items land. Checkboxes reflect reality, not wishes.

## Goal

Turn devin-proxy from "code that works" into a distributable, self-updating CLI
product — **public repo, open distribution** — while keeping this workspace for dev.

## Release flow (steady state)

```
work on master -> commit (conventional) -> CI green

EITHER fully autonomous (preferred):
-> Actions -> release -> Run workflow -> kind = suggest|patch|minor|major
   (cut job bumps + commits + tags + pushes -> tag push triggers the SAME
    workflow's gate+release jobs)
-> GitHub Release published with notes

OR manual:
-> python scripts/bump.py [patch|minor|major] --push
-> release.yml builds wheel+sdist + notes -> gh release

-> devin-proxy update pulls the new wheel
```
